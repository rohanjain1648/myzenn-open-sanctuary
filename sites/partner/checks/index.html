A fictional demo site. This page checks the runtime it uses.

Spec checks

The Worldwide Agentic Web MVP spec (section 6) says a runtime must stop an invalid network, a composition cycle, an over-budget request and a denied origin, with visible errors. These checks run each case live in this tab, through the same runtime as the planner, on its built-in mock model. No key is needed and nothing is sent to any AI provider.

    The fixture networks are in checks/. The cross-site checks with MyZenn, such as consent before contact and the key never reaching MyZenn, run on the planner and in the repository's tests.
